# kus-foto — KUS SOAP
Картинки бренда KUS SOAP для Ozon и Wildberries.

- `rich/` — rich-контент Ozon: 6 блоков для компьютера (`01-hero.jpg` … `06-podarok.jpg`, ширина 1416) и мобильные версии (`m-…`, ширина 1000).
- `kartochki/` — карточки 100 ароматов (11 слайдов на аромат), выгрузка из Figma.
- `logo/` — логотип KUS SOAP: знак «мыло с укусом» (`kussoap-znak-*`) и словесный (`kussoap-logo-*`), PNG 1000, 500 и 200 px.

Прямые ссылки: `https://raw.githubusercontent.com/chmain/kus-foto/main/<путь>`
